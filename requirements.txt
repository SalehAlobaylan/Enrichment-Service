# The default torch wheel pulls ~3 GB of nvidia-* CUDA libraries
# (cublas, cudnn, nccl, cufft, cusolver, cusparse, triton, etc.) that
# we never use on Cranl's CPU instances and that blow past the build
# disk quota. Pin the CPU wheel explicitly via PyTorch's CPU index.
# sentence-transformers + FlagEmbedding both pull torch as a transitive
# dep — putting torch ABOVE them ensures the CPU pin wins.
# See https://pytorch.org/get-started/locally/ for index conventions.
